Laya local API

The Go server accepts JSON and returns native Laya answers. Inference runs locally in a private Python worker.

  • GET /api/health — status for both models; optional ?model=english.
  • GET /api/ready — HTTP 200 when both models are warm; otherwise 503.
  • POST /api/predict — structured state and named questions.
  • POST /api/decide — original prompt, question, and options compatibility endpoint.

Prediction request

Send Content-Type: application/json. Model defaults to typed-decisions; use english to compare.

{
  "model": "typed-decisions",
  "state": {"message": "I was charged twice. Please refund me."},
  "questions": {
    "refund_requested": {
      "type": "noul",
      "instructions": "Does the customer request a refund?"
    },
    "department": {
      "type": "choice",
      "instructions": "Which team should handle this?",
      "criteria": {"billing": "payments and refunds", "technical": "bugs"}
    },
    "urgency": {
      "type": "score",
      "instructions": "How urgent is the message?",
      "criteria": ["low", "medium", "high"]
    }
  }
}

noul remains P(true) in raw JSON. The UI compares yes and no, highlights the winner, and shows a tie at exactly 0.5. Custom false/true labels are respected. choice returns the selected option and distribution. score returns an expected zero-based rubric position.

Use 1–8 questions and 2–8 choice/score criteria. Invalid JSON, duplicate keys, invalid definitions, and inputs exceeding a model's token budget return 422. Requests above 256 KiB return 413; a busy model returns 429; an unavailable model returns 503. Inference times out after two minutes.
